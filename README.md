# An Integrated AI-Powered Learning Platform
This project presents SmartLearn, a comprehensive digital learning platform designed to enhance student engagement, study efficiency, and academic organization. Developed using JavaScript, HTML, and SQL, the platform provides streamlined access to course materials, AI-generated flashcards and summaries, interactive quizzes, and intelligent video search with lecture recommendations.

Additional features include content uploading/downloading, a customizable study timetable, a reading progress tracker, and a task management tool ("Things to Do"). By combining educational tools with AI support, SmartLearn serves as a personalized, all-in-one learning environment that empowers students to study effectively and stay organized throughout their academic journey.
